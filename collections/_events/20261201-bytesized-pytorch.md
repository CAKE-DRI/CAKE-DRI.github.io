The session aims to:
* provide an understanding of the structure of a PyTorch model and Machine Learning pipeline
* introduce the different functionalities PyTorch might provide
* encourage good research software engineering (RSE) practice
* exercise careful consideration and understanding of data used for training ML models

The session will cover the following Machine Learning content:
* using Machine Learning for classification
* artificial neural networks (ANNs) treatment of tabular tables
