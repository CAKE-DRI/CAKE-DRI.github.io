The [Fortran index](https://github.com/fortran-index/fortran-index) hackathon
series aims to improve knowledge exchange within the Fortran programming
community by adding, correcting, and curating the information available in the
[fortran-lang](https://fortran-lang.org) community resource.

Following some great progress with improving navigability via tags in the
[previous hackathon](https://www.cake.ac.uk/events/202607-FortranIndexHackathon7/)
we will continue work on overhauling the
[package index](https://fortran-lang.org/packages/) to make it more useful for
the Fortran community, e.g., enabling filtering by attributes such as GitHub
stars or last commit.

The event will be hosted online, running on Tuesday 6th October 2026 between
14:00 and 16:30 BST (13:00-15:30 UTC). Register for the hackathon by filling out
the following form:
[https://forms.gle/D8JkBUbJFPPqjUVF8](https://forms.gle/D8JkBUbJFPPqjUVF8).
